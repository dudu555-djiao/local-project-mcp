# 0.2.0-beta.1 发布验证

验证日期：2026-10-13。以下是本地检查记录，不代表独立安全审计。

- 31 项 Node 测试通过，包括原有读取能力和官方 MCP SDK 的 HTTP / stdio 真实编辑链：读原文件版本、生成预览、应用后检查实际字节、新建子目录文件、备份恢复。
- 默认与旧配置保持只读；权限关闭、停用、暂停和服务重启令旧提案失效。旧授权也不能读取新版本的私有提案与原始备份。
- 覆盖版本冲突、唯一片段匹配、重复提交、竞争提案、秘密字段保留、UTF-8 BOM / CRLF、符号链接 / 硬链接 / FIFO / 凭据路径拒绝、备份容量限制。
- 故障注入验证审计与备份失败时项目不变；写后元数据或回执 ENOSPC 时报告实际已保存，重启可校验恢复记录；后续外部变化标记 needsReview，拒绝强制覆盖。
- 6 项 Swift Tunnel 健康检查通过。Swift 类型检查与 UI JavaScript 语法检查通过；临时 DOM 检查覆盖编辑确认桥接、历史恢复条件与暂停文案。
- Apple Silicon 应用完成编译与临时签名完整性检查；没有 Apple Developer ID 签名和公证。使用 app 内置 Node、依赖和服务完成 13 工具发现与真实读版本→预览→应用→磁盘字节核验。
- 图形窗口与 ChatGPT 网页端的端到端编辑验收尚待解锁测试电脑后完成，不能将 SDK 集成测试视为网页模型已经实测成功。

版本与路径检查不能替代操作系统隔离。应避免其他编辑器或 Agent 同时保存同一个文件；未进行断电一致性测试。仅支持 UTF-8 源码和文本编辑，本版不执行任意命令、删除文件、修改二进制文档或数据库。

GitHub Actions 会重新运行 Node、Swift 和公开文件检查，结果以仓库 Actions 为准。公开文件与安装包需要再经过隐私扫描；只有通用源码、合成测试与文档可发布。
