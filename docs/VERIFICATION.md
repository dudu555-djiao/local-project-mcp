# 0.1.0-beta.1 发布验证

验证日期：2026-10-12。以下为维护者本地检查记录，不代表独立安全审计。

- 12 项 Node 测试通过，包括路径与符号链接逃逸拒绝、暂停授权立即生效、脱敏、SQLite 只读、Git 索引不变、审计失败时停止返回内容，以及官方 MCP SDK 的 HTTP / stdio 互通。
- 6 项 Swift Tunnel 健康检查通过，覆盖实际轮询成功、缺失轮询、过期、未就绪与异常指标；避免只凭 readyz 显示已连接。
- 在 Apple Silicon Mac 编译，app 与内置可执行文件通过临时签名完整性验证；没有 Apple Developer ID 签名和公证。
- 运行环境下载使用固定发行版本与 SHA256；安装包包含第三方许可证。
- 使用 app 内置 Node、依赖和 MCP 服务完成干净临时目录的启动验证：9 个工具可发现，server_info 成功，预授权文件夹为 0。
- 公开源码扫描及安装包复核排除本机个人目录、连接配置、Tunnel ID、运行密钥、访问日志和原有项目资料；首次授权目录由用户自行选择。
- 本次发布时测试电脑屏幕锁定，未完成新版 GUI 首次启动的交互复测；不同系统的 Gatekeeper 与网页账号端连接仍需使用者按教程验证。

GitHub Actions 会在提交后重新运行 Node、Swift 和公开文件检查，结果以仓库 Actions 为准。当前仅提供 macOS 14+ Apple Silicon 测试包；不宣称已在 Windows、Intel Mac、所有账号和所有网络环境验证。
