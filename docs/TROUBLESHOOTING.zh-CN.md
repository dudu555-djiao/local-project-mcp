# 常见问题

| 现象 | 检查和处理 |
| --- | --- |
| macOS 不允许打开 | 本版未公证。核对来源及校验值后按系统“隐私与安全性”提示处理；不要关闭系统安全保护。 |
| Windows 或 Intel Mac 无法使用 | 此安装包只支持 macOS 14+ / Apple Silicon。源码的原生界面和文档提取也依赖 macOS；尚未完成其他平台适配。 |
| Tunnel / 自定义 MCP 入口不存在 | 检查账号、组织、目标工作空间是否支持；本软件不能绕过平台权限。可先导出 Markdown 文本快照。 |
| 运行密钥要自己编密码吗 | 不是。使用 OpenAI 平台生成的独立运行 API key，限 Tunnels Read + Use。 |
| 为什么要 API key | 官方 Tunnel 客户端需要认证。本软件不调用模型推理 API；不要把它理解为转换订阅额度。 |
| 本地服务运行，但通道一直连接中 | 检查网络及代理，浏览器代理不会自动应用到 Tunnel。填自己的 HTTP 代理 URL，保存后启动连接。 |
| 未找到 MCP 端点 | 保持本软件和 Tunnel 运行，核对 ID、代理、成功轮询和目标工作空间关联；通过连接页“打开连接诊断”检查。 |
| 无法发现 OAuth 设置 | 身份验证明确选择“无需身份验证”，不要选混合 OAuth 选项。 |
| 401 / 403 / Tunnels access required | 核对运行密钥有效期、所属组织与 Tunnels Read + Use；创建管理操作需要 Read + Manage。不要扩大为全部权限来掩盖问题。 |
| ChatGPT 看不到文件夹 | 在正确账号安装并选择插件，调用 list_folders；检查本地全局暂停及文件夹开关。 |
| 新增文件夹后仍看不到 | 再调用 list_folders 获取最新 ID，不需要重建插件。 |
| 升级后模型仍说只能读取 | 在 ChatGPT 插件设置刷新工具列表；确认可见 prepare_edit / apply_edit。旧聊天仍未更新时新建聊天并重新选择插件。 |
| 已安装新版，但编辑被拒绝 | 新加和旧版升级的文件夹默认只读。必须在本机为目标文件夹开启“允许编辑”；检查全局暂停、文件夹启用状态及实际 folderId。模型不能自行授权。 |
| 聊天里有新代码，原文件没变 | 方案或代码块不会自动保存。要求先 prepare_edit，再确认并 apply_edit，最后 read_file 读回；核对真实工具结果。 |
| 提案过期或权限变化 | 提案有效 10 分钟且绑定当前服务实例。重启、关闭编辑、停用或暂停后旧提案失效，重新开启也不能复用。重新读取、重新预览，不要重试旧 proposalId。 |
| 原文件版本不一致 | 文件已被你、Codex 或其他程序修改。重新 read_file 获取 version（SHA256），核对最新内容再生成提案；不要强行覆盖。 |
| 旧文本找不到或出现多处 | 精确替换需要匹配当前原文。重新读取相关行，用足够明确的上下文定位，不要改用整文件覆盖。 |
| 编辑涉及隐藏区域或占位文字 | 读取结果有脱敏。不要替换包含隐藏内容的片段，也不要把占位文字写回；缩小到可见原文上的局部修改。 |
| 某些文件能读但不能编辑 | 编辑仅支持 UTF-8 源码/文本，最大 2 MiB。PDF、DOCX、数据库、凭据、符号链接和硬链接不允许编辑。 |
| 修改请求太大 | 单次请求文本总量最多 50 万字符、最多 20 处替换；拆分修改，且每次成功后重新读取版本。 |
| 如何运行测试或提交 Git | 本版没有命令执行工具。由你在本机运行，或让本地 Codex 核对当前磁盘修改后继续测试。 |
| 恢复被拒绝 | 先 list_changes 确认 canRestore，再 prepare_restore 预览并 apply_edit。当前文件有新变化、权限撤回或备份缺失时不能直接恢复。 |
| 返回 applied: true，但有记录或日志警告 | 文件可能已保存，只是磁盘空间不足等原因使回执未完成。先检查原文件和修改历史，不要重复生成同一修改；检查本机磁盘空间。 |
| 修改历史显示 needsReview | 当前文件与备份无法确认完整保存结果。人工核对文件和备份，记录不可强制恢复；不要假设它表示“未写入”。 |
| 新建文件不能撤销 | 新建记录 canRestore 为 false；本版没有删除工具，需要用户在本机自行处理。 |
| 备份容量已满 | 私有备份累计上限 200 MiB，不自动清理。先确认恢复需求，再在本机归档；不要公开整个 Application Support 目录。 |
| 文件没有全部读完 | 结果会标注分页、截断和过滤；要求模型继续读取下一页。依赖、构建、凭据等目录会排除。 |
| PDF 没有文字 | 只支持可选文本 PDF，不执行 OCR。扫描件先做 OCR 或导出文本。 |
| Word 表格/图片遗漏 | DOCX / RTF 主要提取正文文本，不保证完整保留复杂结构。 |
| SQLite 被占用 | 先由用户制作一致副本，再授权副本目录；工具不执行任意 SQL，也不会修改业务库。 |
| 关闭窗口后还运行吗 | 红色关闭隐藏窗口；⌘Q 或“退出”才停止。电脑休眠时无法读取或修改。 |
| 快速聊天打不开 | 属于桌面客户端入口问题，先保存草稿再重启；也可复制方案到 Codex，不影响 MCP 读取功能。 |
| 能否直接给所有人同一个插件 | 每个人要配置自己的 Tunnel 和凭据。不要共享连接到某个人电脑的插件。 |

## 在本机查看诊断

不要让多个编辑器或 Agent 同时保存同一个文件。工具在读取和保存前检查内容版本及文件属性，检测到变化时会停止；这些检查不是操作系统沙箱，不能替代不同程序之间的协同。

连接页展开“连接诊断与高级信息”，打开官方客户端的本地诊断页面。查看是否持续成功轮询、代理路由是否正确、本地 MCP 探测是否正常。诊断页面不等于端到端读取已经成功。

诊断日志可能含 Tunnel ID、路径等信息。提交 Issue 时仅描述系统/芯片、软件版本、操作步骤和经过处理的错误信息；不要上传日志目录或整个截图。

## 撤销权限与卸载

只想停止编辑时，点击目标文件夹 **关闭编辑**。该文件夹仍可读取，待应用提案立即失效，已经完成的修改保留。想停止全部访问时，点击 **暂停全部访问** 或移除本地授权，退出应用。再在 ChatGPT 移除个人插件、在 OpenAI 平台撤销独立运行 key；不再需要的 Tunnel 可自行删除。删除 app 不会自动删除账号端凭据或本机用户设置。

社区版本机设置及编辑备份在 `~/Library/Application Support/LocalReaderMCP/`。若选择保存密钥，macOS 钥匙串服务名为 `io.localreader.mcp.tunnel`。卸载后可在钥匙串访问中删除该条目。删除用户设置前确认是否还需要修改恢复记录和备份；原始项目不在这个设置目录。
