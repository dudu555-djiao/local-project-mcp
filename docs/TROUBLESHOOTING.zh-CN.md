# 常见问题

| 现象 | 检查和处理 |
| --- | --- |
| macOS 不允许打开 | 本版未公证。核对来源及校验值后按系统“隐私与安全性”提示处理；不要关闭系统安全保护。 |
| Windows 或 Intel Mac 无法使用 | 此安装包只支持 macOS 14+ / Apple Silicon。源码的原生界面和文档提取也依赖 macOS；尚未完成其他平台适配。 |
| Tunnel / 自定义 MCP 入口不存在 | 检查账号、组织、目标工作空间是否支持；本软件不能绕过平台权限。可先导出 Markdown 文本快照。 |
| 运行密钥要自己编密码吗 | 不是。使用 OpenAI 平台生成的独立运行 API key，限 Tunnels Read + Use。 |
| 为什么要 API key | 官方 Tunnel 客户端需要认证。本软件不调用模型推理 API；不要把它理解为转换订阅额度。 |
| 本地服务运行，但通道一直连接中 | 检查网络及代理，浏览器代理不会自动应用到 Tunnel。填自己的 HTTP 代理 URL，保存后启动连接。 |
| 未找到 MCP 端点 | 保持本软件和 Tunnel 运行，核对 ID、代理、成功轮询和目标工作空间关联；通过连接页“打开连接诊断”检查。 |
| 无法发现 OAuth 设置 | 身份验证明确选择“无需身份验证”，不要选混合 OAuth 选项。 |
| 401 / 403 / Tunnels access required | 核对运行密钥有效期、所属组织与 Tunnels Read + Use；创建管理操作需要 Read + Manage。不要扩大为全部权限来掩盖问题。 |
| ChatGPT 看不到文件夹 | 在正确账号安装并选择插件，调用 list_folders；检查本地全局暂停及文件夹开关。 |
| 新增文件夹后仍看不到 | 再调用 list_folders 获取最新 ID，不需要重建插件。 |
| 文件没有全部读完 | 结果会标注分页、截断和过滤；要求模型继续读取下一页。依赖、构建、凭据等目录会排除。 |
| PDF 没有文字 | 只支持可选文本 PDF，不执行 OCR。扫描件先做 OCR 或导出文本。 |
| Word 表格/图片遗漏 | DOCX / RTF 主要提取正文文本，不保证完整保留复杂结构。 |
| SQLite 被占用 | 先由用户制作一致副本，再授权副本目录；工具不执行任意 SQL，也不会修改业务库。 |
| 关闭窗口后还运行吗 | 红色关闭隐藏窗口；⌘Q 或“退出”才停止。电脑休眠时无法读取。 |
| 快速聊天打不开 | 属于桌面客户端入口问题，先保存草稿再重启；也可复制方案到 Codex，不影响 MCP 读取功能。 |
| 能否直接给所有人同一个插件 | 每个人要配置自己的 Tunnel 和凭据。不要共享连接到某个人电脑的插件。 |

## 在本机查看诊断

连接页展开“连接诊断与高级信息”，打开官方客户端的本地诊断页面。查看是否持续成功轮询、代理路由是否正确、本地 MCP 探测是否正常。诊断页面不等于端到端读取已经成功。

诊断日志可能含 Tunnel ID、路径等信息。提交 Issue 时仅描述系统/芯片、软件版本、操作步骤和经过处理的错误信息；不要上传日志目录或整个截图。

## 撤销权限与卸载

先暂停或移除本地授权，退出应用。再在 ChatGPT 移除个人插件、在 OpenAI 平台撤销独立运行 key；不再需要的 Tunnel 可自行删除。删除 app 不会自动删除账号端凭据或本机用户设置。

社区版本机设置在 `~/Library/Application Support/LocalReaderMCP/`。若选择保存密钥，macOS 钥匙串服务名为 `io.localreader.mcp.tunnel`。卸载后可在钥匙串访问中删除该条目。删除用户设置前确认自己的备份；原始项目不在这个设置目录。
