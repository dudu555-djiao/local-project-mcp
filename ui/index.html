运行密钥是平台生成的 API key，不是自己设置的密码。输入 Tunnel ID 和运行密钥。密钥可保存在 Mac 钥匙串中，不写入资料文件或访问记录。若浏览器使用代理，请在配置中手动填入自己的 HTTP 代理地址。

03

添加自定义 MCP，连接方式选择 Tunnel，选择或填写上面的 ID，认证明确选择“无需身份验证 / No authentication”，不要选择混合 OAuth 选项。账户权限由 Tunnel 管理，本地令牌由连接客户端携带。安装插件后，在消息中选择它。

1

选定资料范围

添加项目或工作资料文件夹，并打开读取开关。暂停或移除后，新的读取请求会被拒绝。

2

在 Chat 中提问

选择 Pro 模型和本地资料插件。让 GPT 先列出资料、搜索相关文件，再引用代码和数据分析。

3

交给 Codex

从 Codex 的新聊天打开 Quick Chat，选择已有对话后“添加到 Codex”。入口不可用时复制最终方案到正确的本地项目，让 Codex 先核对再实施。

这一版支持什么

源码、文本、Markdown、JSON、CSV、日志、可选文本 PDF、Word DOCX / RTF、SQLite 和本地 Git 摘要。

图片、音视频、扫描版 PDF 的 OCR、Excel 工作簿和其他数据库格式暂不支持；请另行上传或先导出文本。大型文件、搜索扫描和导出均有上限，返回结果会说明截断情况。

“导出资料”生成经过过滤的 Markdown 快照，方便在连接不可用时手动上传；它不会包含所有格式或保证模型完整阅读每个文件。
